# Fonturi locale

- **Instrument Sans** (interfața) — inclus, licență SIL Open Font License 1.1 (`OFL-InstrumentSans.txt`).
- **Andika** (textul cărților, SIL International, licență OFL 1.1, textul în `OFL-Andika.txt` — preluat din depozitul oficial
  github.com/silnrsi/font-andika la 2026-10-04; însoțește și pachetele livrate, în `Extra/Licente/`) — `Andika-Regular.ttf` și `Andika-Bold.ttf`
  se descarcă automat de `instaleaza.bat` din depozitul oficial Google Fonts. Dacă lipsesc, aplicația te anunță
  (Setări > Diagnostic) și PDF-urile folosesc un font de rezervă.
  Descărcare manuală: https://github.com/google/fonts/tree/main/ofl/andika — pune cele două fișiere în acest folder.
